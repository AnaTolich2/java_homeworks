# Технологии Java (Java Advanced)

Домашние задания курса «Технологии Java» (ИТМО, КТ): коллекции и потоки, рефлексия и кодогенерация, многопоточность, сетевое программирование, RMI, тестирование, интернационализация.

Описание заданий: [kgeorgiy.info/courses/java-advanced](https://www.kgeorgiy.info/courses/java-advanced/homeworks.html)

## Главное

- **Implementor** (ДЗ 5–7): генератор реализаций интерфейсов и классов через Reflection API, компиляция через `javax.tools`, упаковка в запускаемый jar, документация Javadoc.
- **ParallelMapper и IterativeParallelism** (ДЗ 8–9): параллельная обработка списков на собственном пуле потоков, без активных ожиданий и без `Concurrency Utilities`.
- **WebCrawler** (ДЗ 10): потокобезопасный рекурсивный обход сайтов на `Concurrency Utilities` с ограничениями на число загрузок, извлечений и запросов к одному хосту.
- **Банк на RMI** (ДЗ 12–13): удалённые и локальные (сериализуемые) объекты, JUnit-тесты.

## Что отработано

- Collections Framework, `Comparator`, лямбды, Stream API, сплитераторы и коллекторы.
- Reflection API, генерация и компиляция кода во время выполнения, работа с jar и манифестами.
- Потоки, `wait`/`notify`, потокобезопасные структуры, `ExecutorService` и другие `Concurrency Utilities`, корректное завершение и обработка прерываний.
- Сети: UDP, `DatagramSocket`, NIO (`DatagramChannel`, `Selector`), RMI, сериализация.
- Тестирование с JUnit.
- Javadoc, модули Java, сборка из командной строки.
- Интернационализация: `Locale`, `ResourceBundle`, `NumberFormat`, `DateFormat`, `BreakIterator`.

## Сборка и запуск

Задания зависят от интерфейсов и тестов курса (`info.kgeorgiy.java.advanced.*`). Склонируйте [репозиторий курса](https://www.kgeorgiy.info/git/geo/java-advanced-2026) в соседнюю директорию, скрипты в папках заданий рассчитывают на такое расположение.

Для заданий 5–7 в папке `implementor` лежат скрипты сборки jar и генерации документации. Использование:

```
java -jar Implementor.jar <класс> <директория>
java -jar Implementor.jar -jar <класс> <файл.jar>
```

Задания 5–7 связаны друг с другом и собираются вместе.

## Что не включено

Тесты и библиотеки курса не включены, они лежат в репозитории курса.
