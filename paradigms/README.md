# Парадигмы программирования

Домашние задания курса «Парадигмы программирования» (ИТМО, КТ). Курс начинается с Java (контракты, структуры данных, дженерики), затем переходит к функциональному, объектно-прототипному и логическому программированию: JavaScript, Clojure, Prolog. Сквозная задача курса — разбор и вычисление арифметических выражений, которую приходится решать в разных парадигмах.

Описание заданий: [kgeorgiy.info/courses/paradigms](https://www.kgeorgiy.info/courses/paradigms/homeworks.html)

## Что отработано

- Проектирование через контракты: пред- и постусловия, инварианты, тройки Хоара.
- Инкапсуляция и иерархии классов в Java: интерфейс, абстрактный базовый класс, реализации.
- Дженерики и безопасная работа с типами.
- Обработка исключений и дизайн сообщений об ошибках.
- Функции высшего порядка, замыкания, прототипы в JavaScript.
- Неизменяемые структуры данных и работа с последовательностями в Clojure.
- Парсеры: рекурсивный спуск, комбинаторы, DC-грамматики.
- Логическое программирование и унификация в Prolog.

## Запуск

- **Java:** JDK 21 или новее, пакеты соответствуют путям в папках. Пример: `java search.BinarySearch 3 5 4 3 2 1` выведет `2`.
- **JavaScript:** любой современный интерпретатор. Курс использует GraalVM JS, команда указана в комментарии в начале файлов.
- **Clojure:** Clojure 1.11 или новее, файлы можно загрузить через `load-file` в REPL.
- **Prolog:** SWI-Prolog.
