# Введение в программирование (Java)

Домашние задания курса «Введение в программирование» (ИТМО, КТ). Первый курс по Java: от командной строки и ввода-вывода до собственных классов, коллекций и работы с git.

Описание заданий: [kgeorgiy.info/courses/prog-intro](https://www.kgeorgiy.info/courses/prog-intro/homeworks.html)

## Что отработано

- Ввод-вывод в Java: `Scanner`, `Reader`, блочное чтение, кодировки, закрытие ресурсов.
- Проектирование собственных классов: модификаторы доступа, инкапсуляция, выделение общего кода.
- Collections Framework: `List`, `Map`, выбор структуры данных под требуемую асимптотику.
- Обработка граничных случаев: пустые строки, длинные входы, токены на границах буферов.
- Алгоритмические задачи в формате соревнований.
- Работа с git и пакетами Java.

## Запуск

Нужен JDK 21 или новее. Пример для задания «Сумма чисел»:

```
javac Sum.java
java Sum 1 2 -3
```

Решения в каждой папке запускаются аналогично. Если у задания есть особенности запуска (имена входного и выходного файлов, пакет), они описаны в комментарии в начале файла.
